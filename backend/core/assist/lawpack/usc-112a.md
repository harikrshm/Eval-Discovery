---
id: usc-112a
title: Specification: written description, enablement, best mode
source: 35 U.S.C. 112(a)
status: draft
---
Section 112(a) sets what the written part of a patent (the specification) must contain. It must include a written description of the invention, and it must describe how to make and use the invention in full, clear, concise and exact terms so that a person skilled in the field could do so. These two requirements are commonly called written description and enablement. They are meant to make sure the inventor really possessed what is claimed and that the public gets a usable disclosure in exchange for the patent.

The section also calls for the inventor to set forth the best mode of carrying out the invention that the inventor knew of at filing. Since September 16, 2011, failure to disclose the best mode can no longer be used to invalidate a patent or hold it unenforceable, although the requirement is still in the statute.

Whether a specification supports a given claim is a technical, fact-specific question. This summary does not judge it.
